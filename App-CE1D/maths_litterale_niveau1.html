La leçon — Expressions littérales
Variable · Constante · Substitution · Termes semblables · Simplification

Le calcul littéral, c'est utiliser des lettres pour représenter des nombres inconnus ou variables. C'est la base de toute l'algèbre — et un thème central du CE1D belge. Dans ce niveau, tu vas apprendre à lire, évaluer et simplifier des expressions avec des lettres.

📌 Vocabulaire fondamental

Une variable est une lettre qui représente un nombre quelconque (ex : x, a, n).
Une constante est un nombre fixe (ex : 3, −7, ½).
Une expression littérale mélange variables et constantes reliées par des opérations.
Exemple : 3x + 2 est une expression avec la variable x et la constante 2.

🔁 La substitution — Remplacer la variable par un nombre

La substitution consiste à remplacer la variable par une valeur donnée, puis à calculer.
Exemple : pour 3x + 2 avec x = 5 :
→ On remplace x par 5 : 3 × 5 + 2 = 15 + 2 = 17
Attention : 3x signifie 3 multiplié par x (le signe × est omis par convention).

🔗 Termes semblables — Quand peut-on additionner ?

Deux termes sont semblables s'ils ont la même partie littérale (même lettre, même exposant).
• 4x + 2x = 6x ✓ (même lettre x, même exposant 1)
• 3x² + x² = 4x² ✓ (même lettre x, même exposant 2)
• 5a + 3b → on ne peut PAS simplifier (a ≠ b)
• 3x + 2x² → on ne peut PAS simplifier (exposants différents)

⚠️ Le piège classique du CE1D

3x + 2 ≠ 5x — Tu ne peux PAS additionner un terme en x et une constante !
De même : x² + x ≠ x³ (les exposants ne s'additionnent pas comme ça).
Règle d'or : on n'additionne que des termes qui ont exactement la même partie littérale.

4x + 2x
= 6x
Termes semblables : on additionne les coefficients (4+2=6).
3x² + x²
= 4x²
x² = 1·x², donc 3 + 1 = 4. L'exposant ne change pas.
5x − 2x + 3
= 3x + 3
On simplifie 5x−2x=3x. La constante 3 reste seule.

Exercices guidés
3 exercices avec corrigé détaillé · + 1 bonus · Style CE1D belge
Exercice 1 — Calculer une expression pour plusieurs valeurs
Soit A = 3x² + 2x − 1. Calcule A pour x = 0, x = 1 et x = −1.
1
Pour x = 0 :
A = 3×(0)² + 2×0 − 1 = 0 + 0 − 1 = −1
2
Pour x = 1 :
A = 3×(1)² + 2×1 − 1 = 3 + 2 − 1 = 4
3
Pour x = −1 :
A = 3×(−1)² + 2×(−1) − 1 = 3×1 + (−2) − 1 = 3 − 2 − 1 = 0
⚠️ Attention : (−1)² = +1, car un nombre négatif au carré est positif !
✅ A(0) = −1  |  A(1) = 4  |  A(−1) = 0
Exercice 2 — Simplifier une expression
Simplifier l'expression : 8a − 3a + 2a − a.
1
Identifier les termes semblables : 8a, −3a, 2a et −a sont tous des termes en a → ils sont tous semblables.
2
Regrouper : (8 − 3 + 2 − 1) × a (rappel : −a = −1 × a)
= (8 − 3 + 2 − 1) × a = 6a
✅ 8a − 3a + 2a − a = 6a
Exercice 3 — Application : périmètre d'un rectangle
Le périmètre d'un rectangle est P = 2(l + L). Calcule P pour l = 3 cm et L = 7 cm.
1
Substituer : remplacer l par 3 et L par 7 dans P = 2(l + L)
P = 2(3 + 7)
2
Calculer la parenthèse : 3 + 7 = 10
P = 2 × 10
3
Résultat : P = 20 cm
✅ P = 2(3 + 7) = 2 × 10 = 20 cm
⭐ Exercice bonus — Substitution inverse
L'expression 3x + 5 donne le résultat 23 pour une certaine valeur de x.
Retrouve x en réfléchissant à la substitution inversée.
1
On sait que : 3x + 5 = 23
2
On "retire" la constante 5 : 3x = 23 − 5 = 18
3
On "retire" le coefficient 3 : x = 18 ÷ 3 = 6
4
Vérification : 3 × 6 + 5 = 18 + 5 = 23 ✓
x = 6
Astuce : pour trouver x, on annule les opérations dans l'ordre inverse (d'abord la soustraction, puis la division).
