La leçon — La symétrie axiale
Axe de symétrie · Calcul des images · Propriétés · Exemples

La symétrie axiale (ou réflexion) associe à chaque point son symétrique par rapport à une droite appelée axe de symétrie. Le symétrique d'un point M par rapport à un axe (d) est le point M' tel que (d) soit la médiatrice du segment [MM']. La figure « se retourne » de l'autre côté de l'axe.

📌 Symétrie axiale — Définition

La symétrie axiale d'axe (d) fait correspondre à tout point M son symétrique M' tel que :
• (d) est la médiatrice de [MM'] : (d) passe par le milieu de [MM'] et est perpendiculaire à [MM'].

Formules rapides pour les axes principaux :
• Axe des ordonnées (x = 0) : M(x ; y) → M'(−x ; y)
• Axe des abscisses (y = 0) : M(x ; y) → M'(x ; −y)
• Droite y = x : M(x ; y) → M'(y ; x)

🔢 Calcul des images selon l'axe

• Par rapport à x = 0 (axe y) : M(x ; y) → M'(−x ; y)  → on change le signe de x
• Par rapport à y = 0 (axe x) : M(x ; y) → M'(x ; −y)  → on change le signe de y
• Par rapport à x = k : M(x ; y) → M'(2k−x ; y)
• Par rapport à y = k : M(x ; y) → M'(x ; 2k−y)

Exemple : A(3 ; 1) par rapport à x = 0 → A'(−3 ; 1)

Rectangle
2 axes ✓
Les médiatrices des côtés sont des axes de symétrie
Carré
4 axes ✓
2 médiatrices + 2 diagonales
Triangle isocèle
1 axe ✓
La médiatrice de la base

⚠️ Piège : la symétrie axiale inverse l'orientation !

Contrairement à la translation ou la rotation, la symétrie axiale inverse le sens de parcours (horaire devient anti-horaire). C'est une isométrie indirecte (ou opposée).
La diagonale d'un rectangle n'est PAS un axe de symétrie — seules les médiatrices des côtés le sont.

Exercice 1 — Symétrique par rapport aux axes principaux
Calcule le symétrique des points suivants par rapport à l'axe des abscisses (y = 0) :
a) A(2 ; 5)   b) B(−3 ; 1)   c) C(0 ; −4)
1
Règle : symétrie par rapport à y = 0 → on change le signe de y : M(x ; y) → M'(x ; −y)
2
a) A(2 ; 5) → A'(2 ; −5)
3
b) B(−3 ; 1) → B'(−3 ; −1)
4
c) C(0 ; −4) → C'(0 ; 4)
✅ A'(2 ; −5)  |  B'(−3 ; −1)  |  C'(0 ; 4)
Exercice 2 — Reconnaître l'axe de symétrie
Le point A(2 ; 3) a pour symétrique A'(8 ; 3).
a) Quel est l'axe de symétrie ? (Donne son équation.)
b) Vérifie que cet axe est bien la médiatrice de [AA'].
1
a) Le milieu de [AA'] = ((2+8)/2 ; (3+3)/2) = (5 ; 3). Comme y est constant, l'axe est x = 5.
2
b) AA' est horizontal (même y). La médiatrice est donc verticale et passe par x = 5 → l'axe x = 5 est bien perpendiculaire à [AA'] et passe par son milieu.
✅ Axe : x = 5 — c'est la médiatrice de [AA'] ✓
Exercice 3 — Style CE1D belge
Un triangle ABC a pour sommets A(1 ; 2), B(5 ; 2), C(3 ; 6).
a) Combien d'axes de symétrie possède ce triangle ? Justifie.
b) Calcule le symétrique de A par rapport à l'axe des ordonnées (x = 0).
1
a) AB = |5−1| = 4 (horizontal). C est au milieu : xC = 3 = (1+5)/2. Donc le triangle est isocèle en C → 1 axe de symétrie (la médiane issue de C).
2
b) A(1 ; 2) par rapport à x = 0 → A'(−x ; y) = A'(−1 ; 2)
✅ 1 axe de symétrie (triangle isocèle)  |  A'(−1 ; 2)
⭐ Exercice bonus — Axes de symétrie des polygones réguliers
Un polygone régulier à n côtés possède combien d'axes de symétrie ?
Donne le nombre d'axes pour : triangle équilatéral, carré, pentagone régulier, hexagone régulier.
1
Règle : un polygone régulier à n côtés possède exactement n axes de symétrie.
2
Triangle équilatéral (n=3) → 3 axes | Carré (n=4) → 4 axes | Pentagone (n=5) → 5 axes | Hexagone (n=6) → 6 axes
Un polygone régulier à n côtés a n axes de symétrie. Carré : 4 axes, hexagone : 6 axes.
