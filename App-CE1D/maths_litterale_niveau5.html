N4 — Identités remarquables
(a+b)² = a²+2ab+b²
(a−b)² = a²−2ab+b²
(a+b)(a−b) = a²−b²
Piège :
(a+b)² ≠ a²+b²

🎯 Les pièges à éviter absolument au CE1D

1. −(x + 4) = −x − 4 (PAS −x + 4) — le signe change tous les termes.
2. (x + 3)² = x² + 6x + 9 (PAS x² + 9) — ne jamais oublier 2ab.
3. PGCD maximal : 6x + 4 = 2(3x + 2), pas 1(6x + 4).
4. Termes semblables : 5x + 3 ≠ 8x (x et constante ne se combinent pas).
5. (−1)² = +1, pas −1. Le carré d'un nombre négatif est toujours positif.

Exercice 1 — Développer, réduire et substituer
Soit A = (x + 5)(x − 3) − (x + 1)².
a) Développer et réduire A.
b) Calculer A pour x = 2.
1
Développer (x+5)(x−3) par FOIL :
= x² − 3x + 5x − 15 = x² + 2x − 15
2
Développer (x+1)² par 1ère identité :
= x² + 2x + 1
3
Calculer A :
A = (x²+2x−15) − (x²+2x+1)
A = x²+2x−15 − x² − 2x − 1
A = −16
4
A est une constante ! Pour x = 2 : A = −16 aussi.
Vérif directe : (7)(−1) − (3²) = −7 − 9 = −16 ✓
✅ a) A = −16 (constante)  |  b) A(2) = −16
Exercice 2 — Factoriser complètement
Factoriser complètement B = 2x³ − 8x, puis indiquer les valeurs de x pour lesquelles B = 0.
1
Facteur commun : PGCD(2,8)=2, lettre commune=x
B = 2x(x² − 4)
2
Reconnaître x²−4 = x²−2² : c'est la 3ème identité !
x² − 4 = (x+2)(x−2)
3
Factorisation complète :
B = 2x(x+2)(x−2)
4
B = 0 quand l'un des facteurs est nul :
2x = 0 → x = 0
x + 2 = 0 → x = −2
x − 2 = 0 → x = 2
✅ B = 2x(x+2)(x−2)  |  B = 0 pour x ∈ {−2 ; 0 ; 2}
Exercice 3 — Simplifier une expression complexe
Simplifier C = [(x + 3)² − (x − 3)²] ÷ 12, puis calculer C pour x = 5.
1
Développer (x+3)² : x² + 6x + 9
2
Développer (x−3)² : x² − 6x + 9
3
Numérateur :
(x²+6x+9) − (x²−6x+9) = 12x
4
Simplifier : C = 12x ÷ 12 = x
5
Pour x = 5 : C = 5
✅ C = x  |  C(5) = 5 (une belle simplification !)
⭐ Défi bonus — Preuve par le calcul littéral
Démontre que le produit de deux entiers consécutifs impairs s'écrit toujours sous la forme 4k² − 1, où k est un entier.
Indice : deux entiers impairs consécutifs peuvent s'écrire (2k−1) et (2k+1).
1
Écrire les deux entiers : (2k−1) et (2k+1) sont deux entiers impairs consécutifs.
2
Calculer leur produit :
(2k−1)(2k+1) — c'est la 3ème identité ! a=2k, b=1
= (2k)² − 1² = 4k² − 1
3
Vérification avec k=3 : les entiers sont 5 et 7. 5×7=35 et 4×9−1=36−1=35 ✓
(2k−1)(2k+1) = 4k² − 1
C'est une belle démonstration ! Les identités remarquables servent aussi à prouver des propriétés générales sur les nombres.
