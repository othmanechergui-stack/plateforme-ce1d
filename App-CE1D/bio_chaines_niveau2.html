La leçon — Structure d'une chaîne alimentaire
Niveaux trophiques · Sens des flèches · Équilibre écologique

Une chaîne alimentaire est une suite d'êtres vivants dans laquelle chacun mange celui qui le précède. Elle est organisée en niveaux trophiques (du grec trophos = nourriture). Comprendre sa structure permet de prévoir ce qui se passe quand une espèce disparaît.

📌 Les niveaux trophiques — Définition

Un niveau trophique correspond à la position d'un organisme dans la chaîne alimentaire.
• Niveau 1 : les producteurs (végétaux)
• Niveau 2 : les consommateurs primaires (herbivores)
• Niveau 3 : les consommateurs secondaires (carnivores de 1er ordre)
• Niveau 4 : les consommateurs tertiaires (carnivores de 2ème ordre)
Les flèches vont de la proie vers le prédateur : elles indiquent le sens du transfert d'énergie.

🔢 Les règles de base de la chaîne alimentaire

1. Une chaîne commence toujours par un producteur (végétal).
2. Les flèches indiquent "est mangé par" : proie → prédateur.
3. Chaque flèche représente un transfert d'énergie.
4. Si une espèce disparaît, cela perturbe toute la chaîne (effet domino).
5. Les chaînes comportent généralement 3 à 5 niveaux (rarement plus).

herbe → lapin → renard
3 niveaux trophiques
Producteur + 2 consommateurs. Chaîne terrestre classique.
phyto → zoo → sardine → thon
4 niveaux trophiques
Chaîne marine. Compter les maillons = compter les niveaux.

⚠️ Piège classique : le sens des flèches !

La flèche ne va pas vers ce qui mange, elle va de la proie vers son prédateur.
herbe → lapin signifie : "l'herbe est mangée par le lapin" (l'énergie passe de l'herbe au lapin).
Si tu retires le renard, les lapins n'ont plus de prédateur → leur population explose → ils mangent toute l'herbe → l'herbe disparaît. Effet en cascade !

Exercices guidés
3 exercices avec corrigé détaillé · + 1 bonus · Style CE1D belge
Exercice 1 — Compter les niveaux trophiques
Pour chaque chaîne, indique le nombre de niveaux trophiques :
a) maïs → vache → humain
b) rose → puceron → coccinelle → mésange → faucon
c) algue → oursin → loutre de mer
1
Méthode : compter le nombre d'organismes dans la chaîne = nombre de niveaux.
2
a) maïs → vache → humain = 3 niveaux (maïs=N1, vache=N2, humain=N3).
3
b) rose → puceron → coccinelle → mésange → faucon = 5 niveaux.
4
c) algue → oursin → loutre = 3 niveaux.
✅ a) 3 niveaux · b) 5 niveaux · c) 3 niveaux
Exercice 2 — Analyser un déséquilibre
Chaîne : herbe → criquet → grenouille → couleuvre → buse
On chasse toutes les buses (prédateurs au sommet). Décris en 3 étapes ce qui arrive.
1
Étape 1 : Les buses disparaissent → plus de prédateur pour les couleuvres → les couleuvres se multiplient.
2
Étape 2 : Les couleuvres en excès mangent beaucoup de grenouilles → les grenouilles diminuent.
3
Étape 3 : Moins de grenouilles → les criquets se multiplient → ils dévorent l'herbe → l'herbe diminue fortement.
✅ La suppression d'un prédateur sommet déclenche un effet en cascade sur toute la chaîne.
Exercice 3 — Lire une chaîne (style CE1D)
Voici une chaîne : saule → chenille → rouge-gorge → épervier
a) Qui est le consommateur secondaire ?
b) Que mange l'épervier ?
c) Si les chenilles disparaissent, que se passe-t-il pour le rouge-gorge ?
1
a) Le rouge-gorge mange la chenille (consommateur primaire) → il est consommateur secondaire.
2
b) L'épervier mange le rouge-gorge (il est consommateur tertiaire).
3
c) Si les chenilles disparaissent, les rouge-gorges n'ont plus de nourriture → ils diminuent ou disparaissent → les éperviers perdent leur proie et diminuent aussi.
✅ a) rouge-gorge · b) rouge-gorge · c) rouge-gorge et épervier diminuent
⭐ Exercice bonus — Reconstruire une chaîne incomplète
On te donne ces informations :
• Le faucon mange le lièvre.
• La luzerne est mangée par le lièvre.
• Le lynx mange le faucon.
a) Écris la chaîne alimentaire dans l'ordre correct.
b) Combien y a-t-il de niveaux trophiques ?
1
Méthode : identifier le producteur (végétal = luzerne) et enchaîner les prédateurs.
2
a) luzerne → lièvre → faucon → lynx
3
b) 4 niveaux trophiques (luzerne=N1, lièvre=N2, faucon=N3, lynx=N4).
✅ luzerne → lièvre → faucon → lynx | 4 niveaux trophiques
