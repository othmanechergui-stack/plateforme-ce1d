La leçon — Rotation et symétrie centrale
Centre · Angle · Sens direct · Formules pour 90°, 180°, 270°

Une rotation fait tourner chaque point d'une figure autour d'un point fixe appelé centre de rotation, d'un angle donné et dans un sens précis (direct = anti-horaire, ou indirect = horaire). La symétrie centrale est le cas particulier d'une rotation d'angle 180°.

📌 Rotation — Définition

La rotation de centre O et d'angle α associe à tout point M son image M' telle que :
• OM = OM' (même distance au centre)
• L'angle (OM, OM') = α (mesuré dans le sens direct = anti-horaire)

Cas particulier — Symétrie centrale : rotation d'angle 180° de centre O.
M(x ; y) → M'(−x ; −y) si O est l'origine.

🔢 Formules de rotation autour de O(0 ; 0)

• Rotation de 90° (sens direct) : M(x ; y) → M'(−y ; x)
• Rotation de 180° (symétrie centrale) : M(x ; y) → M'(−x ; −y)
• Rotation de 270° (sens direct) = 90° indirect : M(x ; y) → M'(y ; −x)
• Rotation de 360° : retour à la position initiale → M' = M

Le symétrique de A(2 ; 5) par rapport à O(0 ; 0) : A'(−2 ; −5).

⚠️ Piège : sens direct ≠ sens des aiguilles d'une montre !

Le sens direct (ou trigonométrique) est le sens anti-horaire (contraire des aiguilles d'une montre). Une rotation de 90° dans le sens direct est un quart de tour vers la gauche.
La rotation de 90° dans le sens indirect : M(x ; y) → M'(y ; −x).

Exercice 1 — Images par rotation de 90°
Calcule les images par la rotation de centre O(0;0) et d'angle 90° (sens direct) :
a) A(1 ; 0)   b) B(0 ; 2)   c) C(3 ; −1)
1
Formule 90° (sens direct) : M(x ; y) → M'(−y ; x)
2
a) A(1 ; 0) → A'(−0 ; 1) = A'(0 ; 1)
3
b) B(0 ; 2) → B'(−2 ; 0) = B'(−2 ; 0)
4
c) C(3 ; −1) → C'(−(−1) ; 3) = C'(1 ; 3)
✅ A'(0;1)  |  B'(−2;0)  |  C'(1;3)
Exercice 2 — Symétrie centrale
Calcule le symétrique par rapport au centre O(0 ; 0) des points :
a) A(4 ; −2)   b) B(−3 ; −5)   c) C(0 ; 7)
1
Formule 180° : M(x ; y) → M'(−x ; −y) — on change les deux signes
2
a) A(4 ; −2) → A'(−4 ; 2)
3
b) B(−3 ; −5) → B'(3 ; 5)
4
c) C(0 ; 7) → C'(0 ; −7)
✅ A'(−4;2)  |  B'(3;5)  |  C'(0;−7)
Exercice 3 — Style CE1D belge
Le centre de symétrie d'un parallélogramme ABCD est le point O, milieu des diagonales.
Sachant que A(1;1), B(5;1), C(6;4) et D(2;4) :
a) Calcule les coordonnées de O.
b) Vérifie que O est bien aussi le milieu de [BD].
1
a) O = milieu de [AC] = ((1+6)/2 ; (1+4)/2) = O(3,5 ; 2,5)
2
b) Milieu de [BD] = ((5+2)/2 ; (1+4)/2) = (3,5 ; 2,5) = O ✓
3
Les deux diagonales se coupent bien en O → ABCD est un parallélogramme ✓
✅ O(3,5 ; 2,5) — milieu commun des deux diagonales ✓
⭐ Exercice bonus — Ordre d'une rotation
L'ordre d'une rotation est le nombre minimal de fois qu'on doit l'appliquer pour revenir à la position de départ.
a) Quel est l'ordre d'une rotation de 90° ?
b) Quel est l'ordre d'une rotation de 120° ?
c) Quel est l'ordre d'une rotation de 180° ?
1
Règle : l'ordre = 360° ÷ angle de la rotation.
2
a) 360° ÷ 90° = 4 (carré)
3
b) 360° ÷ 120° = 3 (triangle équilatéral)
4
c) 360° ÷ 180° = 2 (symétrie centrale)
Ordre = 360° ÷ angle. Rot. 90° → ordre 4 · Rot. 120° → ordre 3 · Rot. 180° → ordre 2.
