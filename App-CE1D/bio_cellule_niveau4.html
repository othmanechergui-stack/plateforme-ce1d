La leçon — ADN et information génétique
Structure ADN · Bases azotées · Gène · Transcription · Traduction · Mutation

L'ADN (acide désoxyribonucléique) est la molécule qui contient toute l'information génétique d'un organisme. Sa structure en double hélice permet à la fois sa conservation et sa lecture.

📌 Structure de l'ADN — Clés à retenir

L'ADN est formé de deux brins enroulés en double hélice.

Chaque brin est une succession de nucléotides, chacun portant une base azotée :
• Adénine se couple avec Thymine (A-T)
• Cytosine se couple avec Guanine (C-G)

Un gène = une séquence d'ADN qui code pour la fabrication d'une protéine.

🔢 Du gène à la protéine : transcription + traduction

• Transcription : l'ADN est copié en ARN messager (ARNm) dans le noyau.
ADN → ARNm
• Traduction : l'ARNm est lu par les ribosomes pour fabriquer une protéine.
ARNm → Protéine

Dans l'ARN, l'Uracile (U) remplace la Thymine (T).
Une mutation = un changement dans la séquence de bases de l'ADN.

A — T
Adénine-Thymine
Appariement dans l'ADN (2 liaisons H)
C — G
Cytosine-Guanine
Appariement dans l'ADN (3 liaisons H)
ADN → ARN → Protéine
Dogme central
Transcription puis traduction

⚠️ Piège classique : ADN vs ARN

Dans l'ADN : A-T-C-G (Thymine).
Dans l'ARN : A-U-C-G (Uracile à la place de Thymine).
La traduction (ARN → protéine) se passe dans le cytoplasme, pas dans le noyau !

Exercice 1 — Complémentarité des bases
Un brin d'ADN a la séquence : 5'-ATCGTA-3'
Écris la séquence du brin complémentaire, en respectant les appariements.
1
Règle d'appariement : A↔T et C↔G (toujours !)
2
Lecture base par base : A→T | T→A | C→G | G→C | T→A | A→T
3
Brin complémentaire : 3'-TAGCAT-5'
✅ Brin complémentaire : 3'-TAGCAT-5' (antiparallèle)
Exercice 2 — Du gène à la protéine
Remets dans l'ordre les étapes de la synthèse des protéines :
Traduction · ADN dans le noyau · Ribosome lit l'ARNm · Transcription · Protéine produite
1
Départ : L'ADN se trouve dans le noyau avec le gène à exprimer.
2
Transcription (noyau) : l'ADN est copié en ARNm par l'ARN polymérase.
3
Export : l'ARNm quitte le noyau et rejoint le cytoplasme.
4
Traduction (cytoplasme) : le ribosome lit l'ARNm et assemble les acides aminés en protéine.
✅ ADN → Transcription → ARNm → Traduction → Protéine
Exercice 3 — Style CE1D belge : mutation et conséquences
Un gène normal code : A-T-G-C-T-A. Une mutation change le 4ème nucléotide (C → A).
a) Quel est le nouveau brin muté ?
b) Quelle peut être la conséquence pour la protéine ?
1
a) Brin muté : A-T-G-A-T-A (le C est remplacé par A en position 4).
2
b) Conséquence : le codon muté code pour un acide aminé différent → la protéine peut être non fonctionnelle, partiellement active, ou si la mutation est silencieuse, sans effet visible.
3
Impact variable : selon la position et la nature de la mutation, les effets vont de nuls à graves (maladie génétique).
✅ Muté : A-T-G-A-T-A | Conséquence : protéine potentiellement modifiée ou non fonctionnelle.
⭐ Exercice bonus — ADN vs ARN
Liste 3 différences entre l'ADN et l'ARN (structure, localisation, bases).
1
Structure : ADN = double brin (double hélice) | ARN = simple brin.
2
Bases : ADN contient Thymine (T) | ARN contient Uracile (U) à la place de T.
3
Localisation : ADN = noyau (permanent) | ARNm = noyau puis cytoplasme (temporaire).
ADN : double brin, T, noyau permanent | ARN : simple brin, U, cytoplasme transitoire
