La leçon — Équation de réaction chimique
Formules · Coefficients stœchiométriques · Équilibrage

Une équation de réaction chimique est la notation symbolique d'une réaction. Elle utilise des formules chimiques (comme H₂O, CO₂, Fe) et une flèche → pour séparer les réactifs des produits. Des coefficients stœchiométriques (les grands chiffres devant les formules) permettent d'équilibrer l'équation.

📌 Équation de réaction — Définition

Réactifs → Produits

Les coefficients (grands chiffres devant) indiquent le nombre de molécules.
Les indices (petits chiffres en bas) indiquent le nombre d'atomes dans une molécule.

Exemple : 2H₂ + O₂ → 2H₂O
→ 2 molécules de H₂ + 1 molécule de O₂ donnent 2 molécules de H₂O.

🔢 Comment équilibrer une équation ?

Pour équilibrer : compter les atomes de chaque côté → ajuster les COEFFICIENTS (les grands chiffres devant).
JAMAIS modifier les indices (les petits chiffres en bas) : ils définissent la formule du corps.

Exemples équilibrés :
• C + O₂ → CO₂ (déjà équilibrée : 1C et 2O de chaque côté)
• Fe + S → FeS (déjà équilibrée : 1Fe et 1S de chaque côté)
• 2H₂ + O₂ → 2H₂O (coefficients 2 ajoutés devant H₂ et H₂O)

⚠️ Piège classique : Ne jamais changer les formules !

On ne change JAMAIS les formules pour équilibrer une équation !
H₂O ne devient pas H₃O pour équilibrer. On ajoute des coefficients DEVANT : 2H₂O.
Changer un indice change le corps lui-même — H₂O (eau) ≠ H₂O₂ (eau oxygénée) !

Exercices guidés

Exercice 1 — Vérifier si une équation est équilibrée
Pour chaque équation, vérifie si elle est équilibrée (compte les atomes de chaque côté) :
a) Fe + S → FeS
b) H₂ + O₂ → H₂O
c) 2Mg + O₂ → 2MgO
1
a) Fe + S → FeS : Gauche : 1 Fe + 1 S | Droite : 1 Fe + 1 S. ✓ Équilibrée.
2
b) H₂ + O₂ → H₂O : Gauche : 2 H + 2 O | Droite : 2 H + 1 O. ✗ Non équilibrée. Il manque 1 O à droite.
3
c) 2Mg + O₂ → 2MgO : Gauche : 2 Mg + 2 O | Droite : 2 Mg + 2 O. ✓ Équilibrée.
✅ a) Équilibrée ✓ | b) Non équilibrée ✗ | c) Équilibrée ✓
Exercice 2 — Trouver les coefficients manquants
Équilibre l'équation de combustion de l'hydrogène :
H₂ + O₂ → H₂O (non équilibrée)
Trouve les coefficients pour équilibrer sans changer les formules.
1
Étape 1 — Compter : H₂ + O₂ → H₂O | Gauche : 2H + 2O | Droite : 2H + 1O. Il y a 1O de trop à gauche.
2
Étape 2 — Ajouter 2 devant H₂O : H₂ + O₂ → 2H₂O | Gauche : 2H + 2O | Droite : 4H + 2O. Maintenant l'O est bon mais H est déséquilibré.
3
Étape 3 — Ajouter 2 devant H₂ : 2H₂ + O₂ → 2H₂O | Gauche : 4H + 2O | Droite : 4H + 2O. ✓ Équilibrée !
✅ 2H₂ + O₂ → 2H₂O
Exercice 3 — Lecture d'une équation (style CE1D)
Voici l'équation de combustion du méthane : CH₄ + 2O₂ → CO₂ + 2H₂O
a) Combien de molécules de O₂ sont consommées ?
b) Combien d'atomes d'hydrogène y a-t-il dans CH₄ ?
c) L'équation est-elle équilibrée ? Vérifie pour C, H et O.
1
a) Le coefficient devant O₂ est 2 → 2 molécules de O₂ sont consommées.
2
b) Dans CH₄, l'indice de H est 4 → 4 atomes d'hydrogène dans une molécule de CH₄.
3
c) C : 1 gauche = 1 droite ✓ | H : 4 gauche = 2×2=4 droite ✓ | O : 2×2=4 gauche = 2+2×1=4 droite ✓ Équilibrée !
✅ a) 2 molécules O₂ | b) 4 atomes H | c) Équilibrée ✓ (C:1=1 · H:4=4 · O:4=4)
⭐ Exercice bonus — Équilibrer la combustion du propane
Le propane (C₃H₈) brûle selon : C₃H₈ + O₂ → CO₂ + H₂O (non équilibrée)
a) Combien d'atomes de C, H dans C₃H₈ ?
b) Équilibre l'équation en trouvant tous les coefficients.
1
a) C₃H₈ : 3 atomes de C et 8 atomes de H.
2
b) Étape C : 3 C à gauche → coefficient 3 devant CO₂ : C₃H₈ + O₂ → 3CO₂ + H₂O
3
Étape H : 8 H à gauche → coefficient 4 devant H₂O (4×2=8) : C₃H₈ + O₂ → 3CO₂ + 4H₂O
4
Étape O : 3×2 + 4×1 = 6+4 = 10 O à droite → coefficient 5 devant O₂ : C₃H₈ + 5O₂ → 3CO₂ + 4H₂O ✓
C₃H₈ + 5O₂ → 3CO₂ + 4H₂O
Vérif : C: 3=3 ✓ | H: 8=8 ✓ | O: 10=10 ✓
