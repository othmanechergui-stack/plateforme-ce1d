La leçon — La translation
Définition · Vecteur · Calcul des images · Propriétés

Une translation est une transformation géométrique qui déplace tous les points d'une figure de la même façon : même direction, même sens, même distance. C'est comme « glisser » la figure sans la tourner ni la déformer. Ce déplacement est décrit par un vecteur de translation.

📌 Translation — Définition

La translation de vecteur u⃗ = (a ; b) associe à tout point M(x ; y) son image M'(x + a ; y + b).

• a = déplacement horizontal (+ vers la droite, − vers la gauche)
• b = déplacement vertical (+ vers le haut, − vers le bas)

🔢 Calcul de l'image par une translation

Si le vecteur de translation est u⃗ = (a ; b) :

• Image de M(x ; y) → M'(x + a ; y + b)

Exemples avec u⃗ = (3 ; 2) :
• A(1 ; 1) → A'(1+3 ; 1+2) = A'(4 ; 3)
• B(0 ; −1) → B'(0+3 ; −1+2) = B'(3 ; 1)
• C(−2 ; 4) → C'(−2+3 ; 4+2) = C'(1 ; 6)

Longueurs
Conservées ✓
AB = A'B' — la figure garde la même taille
Angles
Conservés ✓
Les angles du triangle ne changent pas
Orientation
Conservée ✓
Le sens de parcours reste le même

⚠️ Piège : le vecteur de translation n'est pas un point !

Le vecteur (3 ; 2) indique un déplacement de 3 vers la droite et 2 vers le haut. Ce n'est pas un point de coordonnées (3 ; 2) — c'est une flèche de déplacement.
Pour trouver le vecteur entre A et A' : u⃗ = (xA' − xA ; yA' − yA).

Exercices guidés

Exercice 1 — Calculer les images par translation
Soit la translation de vecteur u⃗ = (4 ; −2). Calcule les images des points :
a) A(0 ; 0)   b) B(3 ; 5)   c) C(−1 ; 2)
1
Formule : M'(x + a ; y + b) avec a = 4, b = −2
2
a) A(0 ; 0) → A'(0+4 ; 0+(−2)) = A'(4 ; −2)
3
b) B(3 ; 5) → B'(3+4 ; 5+(−2)) = B'(7 ; 3)
4
c) C(−1 ; 2) → C'(−1+4 ; 2+(−2)) = C'(3 ; 0)
✅ A'(4 ; −2)  |  B'(7 ; 3)  |  C'(3 ; 0)
Exercice 2 — Trouver le vecteur de translation
Un point M(2 ; 5) a pour image M'(6 ; 1) par une translation.
a) Quel est le vecteur de translation ?
b) Quelle est l'image de N(−3 ; 0) par cette même translation ?
1
a) Vecteur = (xM' − xM ; yM' − yM) = (6−2 ; 1−5) = (4 ; −4)
2
b) N'(−3+4 ; 0+(−4)) = N'(1 ; −4)
✅ Vecteur : (4 ; −4)  |  N'(1 ; −4)
Exercice 3 — Style CE1D belge
Un triangle ABC a pour sommets A(1 ; 2), B(4 ; 2), C(4 ; 5).
On applique la translation de vecteur u⃗ = (−2 ; 3).
a) Calcule les images A', B', C'.
b) Le triangle A'B'C' est-il congru (identique) au triangle ABC ? Justifie.
1
a) A(1;2) → A'(1+(−2) ; 2+3) = A'(−1 ; 5)
2
B(4;2) → B'(4−2 ; 2+3) = B'(2 ; 5)
3
C(4;5) → C'(4−2 ; 5+3) = C'(2 ; 8)
4
b) Oui, car une translation conserve les longueurs et les angles → les deux triangles sont congruents.
✅ A'(−1;5), B'(2;5), C'(2;8) — Congruents car la translation conserve les distances.
⭐ Exercice bonus — Composition de translations
On applique d'abord la translation t₁ de vecteur (2 ; 1), puis la translation t₂ de vecteur (−3 ; 4).
a) Quel est le vecteur de la translation résultante ?
b) Quelle est l'image de A(0 ; 0) par la composition t₂ ∘ t₁ ?
1
a) La composée de deux translations est une translation de vecteur somme : (2+(−3) ; 1+4) = (−1 ; 5)
2
b) A(0;0) → A'(0+(−1) ; 0+5) = A'(−1 ; 5)
Vecteur résultant : (−1 ; 5) — La composée de deux translations est toujours une translation !
