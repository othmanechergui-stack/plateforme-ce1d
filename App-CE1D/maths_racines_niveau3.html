√(a²) = |a| · Extraire le plus grand carré parfait · Piège √(a+b)

Au niveau 3, on va plus loin dans la simplification : on apprend à extraire le carré parfait le plus grand possible du radicande, et on découvre une propriété importante : √(a²) = |a|. On verra aussi le piège classique de la racine d'une somme.

📌 Propriété fondamentale : √(a²) = |a|

√(a²) = |a| — la racine d'un carré donne la valeur absolue.
Si a ≥ 0 : √(a²) = a   |   Si a < 0 : √(a²) = −a (la valeur positive)
Exemples :
• √(5²) = √25 = 5  |  √(3²) = √9 = 3
• √(a²×b) = a×√b (si a ≥ 0) — on sort le coefficient devant la racine

📐 Méthode : extraire le plus grand carré parfait

Étape 1 : lister les diviseurs carrés parfaits du radicande.
Étape 2 : choisir le plus grand (jamais un plus petit !).
Étape 3 : écrire le radicande comme produit (grand carré) × (reste).
Étape 4 : sortir la racine du carré parfait.

Exemples complets :
• √12 = √(4×3) = 2√3
• √18 = √(9×2) = 3√2
• √50 = √(25×2) = 5√2
• √45 = √(9×5) = 3√5

⚠️ Piège majeur : √(a+b) ≠ √a + √b

On ne peut PAS distribuer la racine sur une addition !
Exemple : √(9+16) = √25 = 5  |  mais √9 + √16 = 3 + 4 = 7
5 ≠ 7 — la formule √(a+b) = √a + √b est FAUSSE.
En revanche, √(a×b) = √a × √b est vraie (pour a,b ≥ 0).

Exercice 1 — Simplifier en extrayant le plus grand carré parfait
Simplifie les racines suivantes : √45, √32, √75. Montre chaque étape.
1
√45 : diviseurs carrés parfaits de 45 → 1, 9. Plus grand : 9.
√45 = √(9×5) = √9 × √5 = 3√5
2
√32 : diviseurs carrés parfaits de 32 → 1, 4, 16. Plus grand : 16.
√32 = √(16×2) = √16 × √2 = 4√2
3
√75 : diviseurs carrés parfaits de 75 → 1, 25. Plus grand : 25.
√75 = √(25×3) = √25 × √3 = 5√3
✅ √45 = 3√5  |  √32 = 4√2  |  √75 = 5√3
Exercice 2 — Vrai ou faux ? Piège √(a+b)
Calcule les deux expressions et dis si l'égalité est vraie : √(25+144) =? √25 + √144
1
Côté gauche : √(25+144) = √169 = 13
2
Côté droit : √25 + √144 = 5 + 12 = 17
3
Conclusion : 13 ≠ 17, donc l'égalité est FAUSSE.
✅ √(25+144) = 13 ≠ 17 = √25 + √144 — la racine NE se distribue PAS sur l'addition.
Exercice 3 — Simplifier √72 (CE1D style)
Simplifie √72. Identifie clairement le plus grand carré parfait diviseur.
1
Diviseurs de 72 : 1, 2, 3, 4, 6, 8, 9, 12, 18, 24, 36, 72
2
Carrés parfaits parmi les diviseurs : 1, 4, 9, 36 → le plus grand est 36
3
Décomposition : √72 = √(36×2) = √36 × √2 = 6×√2 = 6√2
✅ √72 = 6√2   (car 36 est le plus grand carré parfait diviseur de 72)
⭐ Exercice bonus — Simplifier des expressions mixtes
Simplifie et additionne : 2√3 + √12.
1
Simplifier √12 : √12 = √(4×3) = 2√3
2
L'expression devient : 2√3 + 2√3
3
Addition des radicaux semblables : 2√3 + 2√3 = 4√3
2√3 + √12 = 2√3 + 2√3 = 4√3
Astuce : toujours simplifier d'abord, puis additionner les radicaux semblables.
