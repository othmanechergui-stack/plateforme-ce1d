La leçon — Le triangle rectangle et le théorème de Pythagore
Triangle rectangle · Hypoténuse · Cathètes · Triplets · Démonstration

Le théorème de Pythagore est l'un des théorèmes les plus célèbres des mathématiques. Il lie les longueurs des trois côtés d'un triangle rectangle par une formule simple. C'est un outil indispensable au CE1D belge.

📌 Le triangle rectangle

Un triangle rectangle possède un angle droit (90°) entre deux de ses côtés.
Les deux côtés qui forment l'angle droit s'appellent les cathètes (notées a et b).
Le côté opposé à l'angle droit est l'hypoténuse (notée c) — c'est toujours le côté le plus long.

📐 Le théorème de Pythagore

Dans tout triangle rectangle, le carré de l'hypoténuse est égal à la somme des carrés des deux cathètes :

c² = a² + b²

où c est l'hypoténuse, a et b sont les cathètes.

⚠️ Piège à éviter

L'hypoténuse est TOUJOURS le côté en face de l'angle droit, pas forcément le côté vertical ou le côté du bas.
Si le triangle est dessiné dans un sens inhabituel, repère d'abord le symbole de l'angle droit (le petit carré), puis le côté en face de lui : c'est l'hypoténuse.

Exercice 1 — Vérifier un triplet pythagoricien
Vérifie que (5, 12, 13) est un triplet pythagoricien. Montre tous les calculs.
1
Identifier l'hypoténuse : le plus grand nombre est 13, donc c = 13.
2
Calculer a² + b² : 5² + 12² = 25 + 144 = 169
3
Calculer c² : 13² = 169
4
Comparer : a² + b² = 169 = c² → la condition est vérifiée ✓
✅ (5, 12, 13) est bien un triplet pythagoricien car 5² + 12² = 25 + 144 = 169 = 13²
Exercice 2 — Vérifier un deuxième triplet
Vérifie que (6, 8, 10) est un triplet pythagoricien.
1
Hypoténuse : c = 10 (le plus grand).
2
a² + b² : 6² + 8² = 36 + 64 = 100
3
c² : 10² = 100
4
Conclusion : 100 = 100 ✓ → triplet pythagoricien.
Note : (6, 8, 10) = 2 × (3, 4, 5) — un multiple d'un triplet est aussi un triplet !
✅ (6, 8, 10) est un triplet pythagoricien car 6² + 8² = 100 = 10²
Exercice 3 — Ce triangle est-il rectangle ?
Un triangle a des côtés 7, 8 et 10. Est-ce un triangle rectangle ? Justifie.
1
Hypoténuse supposée : c = 10 (le plus grand côté).
2
a² + b² : 7² + 8² = 49 + 64 = 113
3
c² : 10² = 100
4
Comparer : 113 ≠ 100 → la condition de Pythagore n'est pas vérifiée.
✅ Non, ce triangle n'est PAS rectangle car 7² + 8² = 113 ≠ 100 = 10²
⭐ Exercice bonus — Chercher des triplets
Combien de triplets pythagoriciens (a, b, c) avec a < b < c existe-t-il où l'hypoténuse est inférieure à 20 ? Trouve les 5 premiers.
1
(3, 4, 5) : 9 + 16 = 25 = 5² ✓
2
(5, 12, 13) : 25 + 144 = 169 = 13² ✓
3
(6, 8, 10) : 36 + 64 = 100 = 10² ✓ (multiple de (3,4,5))
4
(8, 15, 17) : 64 + 225 = 289 = 17² ✓
5
(9, 12, 15) : 81 + 144 = 225 = 15² ✓ (multiple de (3,4,5))
5 triplets : (3,4,5) · (5,12,13) · (6,8,10) · (8,15,17) · (9,12,15)
Astuce : les multiples d'un triplet sont aussi des triplets pythagoriciens !
